# DESIGN — IbrahimOS

**Direction:** Sahel Canopy  
**Chosen:** August 1, 2026 (no UI screenshot provided)

## What

- Surfaces: cool sage / olive wash (`#E7EDE6`), not warm cream
- Ink: deep forest (`#14201A`)
- Accent: living green (`#2D6A4F`)
- Primary CTA metal: harvest gold (`#C9A227`) only on primary buttons
- Type: **Newsreader** (display) + **Sora** (UI)
- Light mode for marketing; brand-forward full-bleed hero, no inset media cards in the first viewport

## Why

African agri-tech credibility without Cloud Grant fingerprint defaults (purple SaaS, cream/brass editorial, Geist/Inter-only, broadsheet, glow/pill soup). Distinct type pairing and cool field palette so a logo swap would not match a sibling org.

## Marketing vs app

Marketing uses these tokens now. Dashboard (Phase 05+) may share the same palette for cohesion within this org only.
